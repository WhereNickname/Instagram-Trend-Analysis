# Instagram Trend Analysis

인스타그램 트렌드를 분석하는 팀 프로젝트야. 현재는 저장소 준비 단계이며 앱 구현과 기술 스택은 아직 정하지 않았어.

## 같이 작업하기

Windows와 macOS에서 각자 저장소를 복제해서 작업해.

```sh
git clone https://github.com/WhereNickname/Instagram-Trend-Analysis.git
cd Instagram-Trend-Analysis
```

작업 전에는 `git pull --ff-only`로 최신 변경을 받아. 기능별 브랜치에서 작업하고 Pull Request로 변경을 공유해. 파일 이름은 영문 소문자와 하이픈을 우선 사용하고, 대소문자만 다른 이름은 만들지 않아.

텍스트는 UTF-8과 LF 줄바꿈을 사용해. 실행 절차는 두 운영체제에서 쓸 수 있게 작성하고, 개인 절대 경로를 코드에 넣지 않아. API 키와 계정 정보는 커밋하지 않아.

공개 저장소는 누구나 읽을 수 있어. 팀원이 직접 push하려면 저장소 Settings → Collaborators에서 GitHub 계정을 초대해야 해.
